# Diagramas, imagens e manuais do CarlioOS

Esta pasta reúne a documentação visual para consulta rápida. Os desenhos
distinguem o que funciona no protótipo do que ainda está planejado.

## Conteúdo

- [`imagens/arquitetura.svg`](imagens/arquitetura.svg): camadas do kernel até os programas.
- [`imagens/layout-diretorios.svg`](imagens/layout-diretorios.svg): layout modular desejado.
- [`diagramas/boot.svg`](diagramas/boot.svg): inicialização e modo degradado atuais.
- [`diagramas/hermione-gravacao.svg`](diagramas/hermione-gravacao.svg): escrita e montagem do Hermione v2 atual.
- [`diagramas/userland.svg`](diagramas/userland.svg): fluxo planejado de login e execução.
- [`diagramas/instalacao-beta.svg`](diagramas/instalacao-beta.svg): alvo futuro do instalador seguro para o NAS.
- [`manual/MANUAL.md`](manual/MANUAL.md): construção, teste, boot e limites.
- [`configuracao/CONFIGURACAO.md`](configuracao/CONFIGURACAO.md): opções existentes e configuração planejada.
- [`configuracao/teste-local.env.example`](configuracao/teste-local.env.example): variáveis aceitas pelo harness local.

SVGs podem ser abertos no navegador e ampliados sem perda de qualidade.
